# Security Policy

## Supported Versions

Only the latest version will be getting security updates.

## Reporting a Vulnerability

Do not open a public issue for a vulnerability.
[Report it privately](https://github.com/henrikwidlund/unfoldedcircle-oppo/security/advisories/new).

Expect an answer within a week. If there is no response within that time, add a comment to your private report.
Resolution time depends on the nature of the problem and if the issue is caused by third party code or not.
